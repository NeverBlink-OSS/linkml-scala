Install the ohi command-line tool to search and download ontologies from your terminal.
The same tool also runs the [LinkML commands](https://linkml.ohi.dev/docs/), under `ohi linkml`.
For Python or TypeScript applications, see [SDK installation](/docs/reference/sdks/#installation).

## Install

Supports Intel and Apple silicon Macs running macOS 14 or later, Linux on x86_64 or arm64,
and Windows on x86_64.

<Tabs>
  <TabItem label="Bash / Zsh">
    Run this in Zsh on macOS, Bash on Linux, or Git Bash, MSYS2, Cygwin or WSL on Windows:

    ```sh
    . <(curl -sSfL https://ohi.dev/install.sh)
    ```

    The [installer](https://github.com/NeverBlink-OSS/ohi/blob/main/cli/install.sh)
    downloads the latest release, verifies its checksum and puts `ohi` in `~/.local/bin`.
    Accept its offer to add that directory to your shell profile so `ohi` works in new terminals too.

    Run the same command again to update.
  </TabItem>
  <TabItem label="PowerShell">
    Run this in Windows PowerShell 5.1 or PowerShell 7:

    ```powershell
    irm https://ohi.dev/install.ps1 | iex
    ```

    The [installer](https://github.com/NeverBlink-OSS/ohi/blob/main/cli/install.ps1)
    downloads the latest release, verifies its checksum and puts `ohi.exe` in `$HOME\.local\bin`.
    Accept its offer to add that directory to your PowerShell profile so `ohi` works in new terminals too.

    Run the same command again to update.
  </TabItem>
</Tabs>

## Check the installation

```sh
ohi version
```

You should see the installed version. Then [download your first ontology](/docs/getting-started/first-ontology/).

## Installer settings

Both installers take the same environment variables:

| Variable | Effect |
| --- | --- |
| `LINKML_SCALA_VERSION` | Install this release tag instead of the latest one. |
| `LINKML_SCALA_INSTALL_DIR` | Install into this directory instead of `~/.local/bin`. |
| `LINKML_SCALA_REQUIRE_CHECKSUM=1` | Refuse releases that publish no checksum file. Releases up to and including v0.12.0 have none. |

## Other ways to install

### mise

If you use the [mise](https://mise.jdx.dev/getting-started.html) tool manager, on any platform:

```sh
mise use 'ubi:NeverBlink-OSS/ohi[matching=ohi,exe=ohi]'
```

### Manual download

Download the `ohi` binary for your system and architecture from
[the latest release](https://github.com/NeverBlink-OSS/ohi/releases/latest).

On macOS and Linux, rename it, make it executable and run it:

```sh
mv ohi-<os>-<arch> ohi
chmod +x ohi
./ohi version
```

On Windows, rename it and run it:

```powershell
ren ohi-windows-x86_64.exe ohi.exe
.\ohi.exe version
```

### Java

On other systems, download `ohi.jar` from the same release and run it with Java 17 or later:

```sh
java -jar ohi.jar version
```

## Verify a download

Each release publishes a `SHA256SUMS` file and a signed build provenance attestation, so you can
check that a download came from our release workflow. The installers check the checksum for you.
To check a manual download, see
[Verifying downloads](https://linkml.ohi.dev/docs/verifying-downloads/).
