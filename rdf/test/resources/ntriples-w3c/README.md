# W3C RDF 1.1 N-Triples test suite

The `.nt` files of the [RDF 1.1 N-Triples test suite](https://w3c.github.io/rdf-tests/rdf/rdf11/rdf-n-triples/),
taken verbatim from `rdf/rdf11/rdf-n-triples/` in <https://github.com/w3c/rdf-tests> at commit
`369a90d1a60c021b746df2e411da0ff36258a758`.

All are syntax tests. Negative ones (the input must be rejected) are exactly those with `-bad-` in
the file name, which matches `manifest.ttl`.
