# W3C Turtle test suite

The [W3C Turtle test suite](https://www.w3.org/2013/TurtleTests/): the `.ttl` test inputs, the
`.nt` expected results of the evaluation tests, and `manifest.ttl`, which says which is which. All
taken verbatim from <https://www.w3.org/2013/TurtleTests/TESTS.tar.gz>.
